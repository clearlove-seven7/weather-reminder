# 小白部署步骤（照着点就行，全程浏览器，不用装软件、不用敲命令）

---

## 你要上传什么？

**把电脑上整个 `weather-reminder` 文件夹传上去**，里面一共 10 个文件（不用记，整个文件夹拖上去就行）：

| 文件 | 是干嘛的 |
|---|---|
| `.github/workflows/weather-alert.yml` | **最重要**：7×24 定时"闹钟"，每 15 分钟自动检查一次 |
| `main.py` | 主程序：判断会不会下雨/下雪 |
| `weather_provider.py` | 查天气的代码 |
| `pushplus.py` | 发微信消息的代码 |
| `config.example.json` | 城市配置（长春、阳泉已经填好了） |
| `README.md`、`test_logic.py`、`run_local.bat`、`test_push.bat`、`state.json`、`.gitignore` | 说明和辅助文件 |

⚠️ 注意：**必须整个文件夹拖进去**（而不是只拖里面的文件），因为 `weather-alert.yml` 藏在一个叫 `.github` 的隐藏文件夹里，漏了它就不会自动提醒了。

---

## 第 1 步：注册 PushPlus 拿 token（必须，否则微信收不到消息）

1. 浏览器打开 👉 <https://www.pushplus.plus/>
2. 点「登录」，**用微信扫码**
3. 第一次会提示关注公众号「**pushplus 推送加**」，用微信扫码关注（不关注收不到）
4. 登录后网页上有一行**你的 token**（一长串字母数字），复制它，先粘贴到记事本里存着

## 第 2 步：注册 GitHub（没有账号的话，5 分钟）

1. 打开 👉 <https://github.com/> ，点 **Sign up** 注册，注册完登录

## 第 3 步：新建仓库（放程序的地方）

1. 登录后点右上角 **+ 号 → New repository**
2. **Repository name** 填：`weather-reminder`
3. 可见性选 **Public**（公开，这样定时任务免费不限量；你的 token 存在 GitHub 的保险箱 Secrets 里，不会泄露）
4. 点绿色按钮 **Create repository**

## 第 4 步：把文件夹传上去（关键一步）

1. 新建完会进入一个页面，中间有一行文字，里面有个蓝色链接叫 **"uploading an existing file"** —— 点它
2. 进入上传页面后，**把电脑上的 `weather-reminder` 文件夹整个拖进网页**
   - 拖进去后页面会列出里面所有文件，**确认能看到 `.github/workflows/weather-alert.yml`**
3. 页面下方 **Commit changes** 那里随便写点字（比如"第一次上传"）
4. 点绿色按钮 **Commit changes**，等它传完自动回到仓库主页

## 第 5 步：把 token 告诉 GitHub（保险箱 Secrets）

1. 仓库页面点最上面的 **Settings**（齿轮图标）
2. 左边菜单依次点 **Secrets and variables → Actions**
3. 点绿色按钮 **New repository secret**
4. **Name** 填：`PUSHPLUS_TOKEN`
5. **Value** 粘贴：第 1 步复制的 token
6. 点绿色 **Add secret**

## 第 6 步：手动发一条测试消息（验证全链路）

1. 回到仓库页面，点最上面的 **Actions**
2. 左边列表点 **「微信雨雪提醒」**
3. 右边点 **Run workflow** 按钮 → **mode** 选 `test` → 点绿色 **Run workflow**
4. 页面上会出现一条运行记录，等 1~2 分钟，黄色圆点变成绿色 ✓
5. 这时你的**微信**应该收到一条：「✅ 测试消息：长春 提醒服务正常」

**收到这条 = 全部搞定！** 之后它每 15 分钟自动查长春和阳泉的天气，预报 1 小时内要下雨/下雪就提醒你，什么都不用再管。

## 常见卡点

| 卡住了 | 怎么办 |
|---|---|
| 打不开 github.com | 网络问题，换个网络或过一会儿再试 |
| 拖文件夹没反应 | 点上传页面中间的文字/虚线框，用文件选择器选中 `weather-reminder` 文件夹 |
| Run workflow 按钮是灰的 | 检查第 5 步 Secrets 是否添加成功 |
| 微信没收到测试消息 | 确认关注了「pushplus 推送加」公众号；确认 token 粘贴时没多空格；再看 Actions 运行日志是不是红色 |
| 运行日志是红色 | 点开红色那行看提示，或把日志截图发给我，我帮你看 |

## 关于安卓手机？

**现在这版不需要手机做任何事**，固定查长春和阳泉两个城市，手机装着微信能收消息就行。以后想要"跟随手机定位自动换城市"，再告诉我，我给你加安卓的定位上报（用 Tasker 自动把坐标发给云端）。
